# 原版资料自动索引

Mod 0.2.2 起使用 `GameKnowledgeCatalog.json` 保存只读的原版资料目录。它位于 Unity 的持久化目录 `AIWorldPawnshop` 下，不随分享包分发，也不包含接口密钥。删除此文件只会使下次进入游戏时重新建立目录，不会删除存档或世界状态。

## 更新过程

1. 进入游戏时先载入上次完整目录，并在后台检查原版 `GameAssembly.dll`、IL2CPP 元数据、主要 assets、Addressables catalog 和 bundle 文件。
2. 文件大小及修改时间没有变化时直接复用上次的哈希；有变化时才重新计算该文件的 SHA-256。目录格式版本也参与总指纹。
3. 内容指纹不变则不扫描。指纹变化或首次安装时，等原版存档与物品目录就绪，在主线程每帧最多读取 6 个物品条目。扫描期间旧目录保留在磁盘供失败回退，但不向模型提供可能过期的条目；成功后原子替换缓存。
4. 某个物品读取失败会跳过；若整轮目录始终为空，保留旧文件，不写入一个空目录。对话期间新观察到的人物、物品与公开事件会增量收录。

缓存中保存物品的原版标识、显示名、描述、基础价值与类型；人物只存原版已介绍的公开姓名、顾客分类和明确的治安职业线索；事件只存已知且非隐藏的活动事件。柜台上的当前交易物和玩家已摆出的物品才会标记为玩家已见，顾客未展示的随身货物不会因此公开。聊天仍直接读取当前原版人物、交易状态、物品数值和活动事件，缓存不是实时状态的替代品。

## 可见性与边界

- 人物模型只按玩家当前提问检索最多 3 个**已见过**的物品、2 个已见过的人物、2 个曾公开的事件。人物条目不授予当前说话者对第三人的私人知识；历史事件不视作仍在发生。
- GM 可查询匹配的原版物品条目用于核对，但这不会让人物自动透露未见过的物品或剧情内容。
- 公开的世界与阵营概况仍使用经核对的精简基础资料。原版资源里的任意文本不能靠关键词自动判定为“公共事实”；角色台词、秘密文档和隐藏事件尤其不能全量广播给顾客。
- 自动发现新物品或事件**不等于**自动获得修改它们的权限。GM 的可执行接口、字段白名单和原版版本兼容性仍需单独测试。Mod 当前验证目标仍是 Probably Stolen Demo 0.46D。

资料目录是只读索引，不修改原版资源。指纹检查失败、原版目录未就绪或新目录构建失败时，保留旧目录并记录日志；当前对话仍可使用原版实时上下文。
