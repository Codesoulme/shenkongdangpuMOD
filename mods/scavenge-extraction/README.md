# 搜打撤！拾荒！

**0.1.0 本地玩法原型**。在原版夜间拾荒地点上方加入交互地图，下方继续使用原版地面、夜间背包和口袋。无需快捷键面板，不包含等级系统。

## 怎么玩

1. 在游戏“模组 → 本地模组”启用《搜打撤！拾荒！》，按游戏要求正常重新进入。
2. 准备夜间背包，把原版武器、散装子弹、防具和绷带等装进去。
3. 夜间照常前往原版拾荒地点。上方左侧为独立的“信息”栏，放大显示状态和最近记录，右侧为地图/战斗区域；口袋#2右侧显示战斗属性，以及独立的武器、防具槽。上下窗口按实际内容宽高分别水平居中，自动缩放以容纳完整内容。将真实物品拖入相应槽位穿戴，取出则卸下。
4. 点击相连地点移动，再点击“拾荒”，直接调用原版拾荒流程，在地面生成物品。不再生成灰黑问号，也没有放大镜动画或搜索等待；保留原版次数、天赋、扫描器、事件、幸运/伤势及背包发现规则。把物品拖入背包才会带走。原版判定受伤或空手而归时，仍按原结果处理。
5. 地图用亮色边框和“你在这里”指示当前位置，未知区域保持清晰文字。有人的新遭遇可出现1～3名NPC，操作按钮下方并排显示照片卡片；底部直接显示各自姓名，边框和姓名底板使用原版阵营颜色，立绘保留清晰原色。右侧没有额外说明文字。点击某张头像展开对应的“对话 / 攻击 / 偷窃”。阵营声望影响对方主动进攻和求饶成功率。拾荒可能引发战斗，旁人也可能抢走地面战利品。
6. 交战按钮只有攻击、防御、逃跑。药品直接在原版背包里右键“摄入/激活”（按物品的原版菜单显示）；每次只消耗1份，并消耗一个战斗回合。没有新增道具面板、切换装备或快捷搜刮按钮。攻击消耗1发同口径的**散装子弹**；弹盒请先用原版操作取出，近战和徒手不用弹药。防御降低本回合所受伤害60%，逃跑成功回到入口。
7. 对手生命归零后选择击杀、击晕或放走。尸体占2×3格，双击打开原版装备/物品栏；随身携带刀具，右键“肢解尸体”。请先取空装备，肢解产物在其物品栏内。
8. 撤离按钮只在入口或应急撤离口、且没有搜索或战斗待处理时出现。原版会提示地面遗留物；随身背包、口袋和装备槽内的物品带回店内。装备会先交还原版背包或店内库存，之后恢复原始口袋布局。

### 人物互动

- 对话：按阵营关系显示简短交流，使用原版确认弹窗；本版不生成额外任务。
- 偷窃：每名NPC只能尝试一次。成功偷取其随身绷带，放进随身容器，放不下时落到地面；之后尸体/装备包不会再次生成这份绷带。失败会降低阵营关系并触发对方攻击。
- 把背包或口袋内的医疗品拖到某张人物照片，或交战画面中的敌人立绘，可以为存活且受伤的对方治疗。每张卡片有独立目标，治疗、偷窃、战利品和处置分别记录。原版拖拽先完成清理，再消耗1份；满生命、无对应效果、倒下或已离场的目标不消耗物品。战斗仍为单个对手的回合制，期间锁定当前对手，治疗仍占用一回合。
- 有效治疗每名NPC首次改善其阵营声望1点；后续仍可治疗，但不会反复刷声望。记录随游戏存档保存。
- `EnemyItemEffects.Register` / `Resolve` 预留人物定向物品效果，支持单份治疗或伤害，未来可接入炸药等；**本版没有默认给所有原版炸药增加投掷效果**。
- 战斗窗口顶部显示“交战”，阵营靠左并使用原版背包/战斗属性表头同款的机械标签，姓名居中突出；立绘放大且无脸部准星。信息和日志移至左栏并放大，空间不足时优先保留最新记录，不缩小文字。
- 命中有立绘震动，枪械有后坐力；优先播放当前武器原有的 `soundUse`，分别对应原版枪械、刀具和钝器音效。敌方头顶显示金黄色伤害，我方生命栏附近显示红色受伤数字；使用加粗黑描边，先清晰停留再上飘淡出。显示实际扣除的生命，不显示超出剩余生命的过量伤害；流血也有反馈，同一瞬间我方连续受伤合并显示。

## 原型覆盖范围

| 需求 | 本版实现 |
|---|---|
| 上方交互地图 | 8个相连节点、探索标记、当前位置、相邻可达限制、两处撤离点 |
| 人物与敌人属性 | 100生命；原版枪械现有火力/精度映射伤害和命中；防具使用现有护甲并损耗；敌人参考其原版武器 |
| 无等级强化 | 独立原版物品槽实际存放武器、防具，原版背包直接使用医疗与兴奋类物品，不复制装备 |
| 持续伤势 | 生命、流血、装备选择写入当前游戏存档；跨天和撤离不回血 |
| 原版悬浮介绍 | 在原有内容之后追加“—— / 拾荒 / 效果”，按效果、数值及使用方式分行，不替换游戏原描述 |
| 阵营与随机角色 | 复用下层、黑市、安保、革命、教会、卡特尔；通用前缀加职业，通用立绘；每处新遭遇1～3人，独立卡片和记录，不调用剧情角色 |
| 拾荒与争夺 | 点击拾荒直接执行原版掉落流程；不再生成蒙版和等待；旁人可能挑衅/抢夺 |
| 第一人称战斗 | 上方地图内切换战斗；使用原版角色、手臂、枪口火光、伤口和倒地帧、音效，配合回合按钮 |
| 战后搜刮 | 击杀/击晕/放走；2×3尸体、原版风格武器/防具/物品格，持刀右键肢解，防重复结算 |
| 战败与结局 | 声望影响求饶概率，成功没收全部随身物品和背包、留1生命；认命或失败使用原版失败画面及本模组文案 |

药物当前支持：绷带20、止血绷带30、外用绷带25（均止血）；药膏15、血袋40；咖啡因片强化6次行动、嗅盐强化3次。强化增加伤害4、命中8。流血每次行动扣1至3生命，需要止血。

## 原型边界

- 地面是本次拾荒共用的原版地面，不是每个节点一张独立场景；节点限制遭遇，未装包物品不会自动捡走。取消每节点两次的旧搜索点限制，拾荒次数由原版统一处理。
- 固定小地图、回合制战斗、概率遭遇；不是实时射击。近战数值是本模组配置，枪械数值来自原物品。尸体和肢解产物使用自制占位图，产物暂不作为食品。
- 战斗使用本模组的生命/流血处理伤势；原版拾荒过程和日间原有伤情仍由原版处理。原版新伤可能阻止继续拾荒，本版没有将两套伤势数值合并。
- 旧版单人遭遇存档保留原角色，不会强行重新抽取；未探索区域或下一夜的新遭遇可以出现多人。旧版遗留问号里的真实物品会直接还原到地面；空间不足时保留可打开的兼容容器取物，不重新抽奖或扣次数。
- 战斗画面只重组本机已有视觉和音效，**不会调用原版 Shoot 杀死店内剧情顾客**。枪口/后坐力按原动作时序重现，倒地使用原版帧。
- 本版只为已列出的医疗品提供拾荒效果，不把任意混合液体当药。`ScavengingEffects.Register` 和 `ResolveChemicalEffect` 预留按成分、剂量接入的扩展入口；不会饮用未知化学品。
- 击晕会留下装备包，放走不掉落。尸体武器及少量补给可搜刮，防具格预留给后续装备生成。
- 使用原版保存时机；本模组不另建自动存档、不删除原有存档。载入晨间存档恢复晨间生命/地图记录；失败后仍可按原版方式读档。
- 可能与接管同一个拾荒按钮/夜间地点的其他玩法模组冲突。本模组不联网、不执行外部程序、不读外部文件，不需要开发者模式。
- 会修改存档并可能损失携带物。推荐测试存档；停用前先取出所有尸体和模组容器里的有价值物品。

## 构建、验证和部署

```powershell
python .\scripts\generate-icons.py
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\deploy-local.ps1
```

发布包：`dist/ScavengeExtraction/`。本地部署目录：`E:\SteamLibrary\steamapps\common\Probably Stolen\Mods\ScavengeExtraction`。仅本地，不上传工坊。

构建不打包游戏DLL、原版图片或反编译代码。纯逻辑回归覆盖伤势、跨天、装备引用、地图可达、声望概率、战败锁定、战后幂等结算、含左侧信息栏的窗口边界与居中、多个NPC的目标隔离/存档迁移、治疗/偷窃限制及撤离显示条件；构建工具另外调用本机游戏实际 `ModScanner.Scan` 检查权限。构建与逻辑通过不代替游戏内画面、声音和背包拖放试玩。

官方依据：[制作资料](https://github.com/dragonpan2/probably-stolen-modding)。当前安装版没有文档新版本的 `AddEnding`，因此直接使用本机已有的原版 `GameOverUIManager` 与 `RunStats`。旧项目《无限轮回》仅参考节点地图和操作区的组织方式，没有搬入等级体系。
